# 🔄 Scikit-Learn-Pipeline 🚀

---

## ✨ Project Goals
- 🤖 Build an end-to-end machine learning workflow using **Scikit-Learn Pipeline**
- 🧹 Automate data preprocessing, feature engineering, and model training in a single reusable pipeline
- 📈 Improve code readability, maintainability, and reproducibility for machine learning projects
- 🎓 Demonstrate best practices for integrating preprocessing techniques with predictive models
- 🔮 Provide a scalable foundation for deploying robust machine learning workflows on real-world datasets

---

## ⚡ Features
- ✅ Creates an end-to-end **Scikit-Learn Pipeline**
- ✅ Automates:
  - 📍 Data Preprocessing
  - 📍 Feature Scaling
  - 📍 Feature Transformation
  - 📍 Model Training
  - 📍 Prediction
- 📊 Evaluates model performance using standard regression metrics
- 🏠 Uses the **King County House Sales** dataset for real-world regression experiments
- 🧮 Eliminates repetitive preprocessing code by combining all steps into a single workflow
- 🚀 Produces clean, reusable, and production-ready machine learning code
- 🛠️ Built with popular libraries: `numpy`, `pandas`, `matplotlib`, `scikit-learn`

---

## 🚀 How to Run

1. 🔗 Clone the repository:

```bash
git clone https://github.com/Ramtin-Ebrahimi/Scikit-Learn-Pipeline.git
```

2. 📂 Navigate to the project folder:

```bash
cd Scikit-Learn-Pipeline
```

3. 📦 Install the required libraries:

```bash
pip install numpy pandas matplotlib scikit-learn
```

4. ▶️ Launch Jupyter Notebook:

```bash
jupyter notebook Sklearn_Pipeline.ipynb
```
